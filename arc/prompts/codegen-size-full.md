As short as the tests allow; one page file per route. Mechanisms (follow exactly): (1) every page contains the literal `<!--NAV-->` and no other navigation links; before sending, the server replaces it with the navigation the specs expect: the signed-out links (texts and hrefs copied verbatim from the tests) or, when the session cookie is valid, the current user name in one element plus the sign-out link the tests look for. (2) Session cookie exactly `session=TOKEN; Path=/; HttpOnly; SameSite=Lax`; sign-out clears it and redirects to /. (3) Validation: every value the test helpers produce (see the support files) is valid input and MUST be accepted; reject only the cases the tests assert are rejected; each message is the FIRST alternative of the test's regex copied verbatim, shown in one persistent `role=alert` element. (4) Elements the test expects visible have a non-empty box (never an empty div/span). (5) No HTML5 validation attributes (required/pattern/type=email): the server validates.
